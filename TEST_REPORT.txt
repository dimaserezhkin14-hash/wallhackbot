WallHack Pro native C++/WASM engine — verification report

Build
- C++ engine compiled to WebAssembly with clang -O3 -flto.
- Web UI calls the engine from engine.worker.js, so search does not block the page.
- UI search budget: 17,000 nodes; main-thread safety timeout: 1.9 s.

Important limitation
- This is a strong compact Quoridor search, not a solved tablebase or tournament-strength perfect player.
- The engine prioritizes tactical walls on the opponent’s actual shortest path, uses alpha-beta, iterative deepening and a transposition table, and validates wall legality/path existence.
- The UI has a 1.9 s safety fallback so a slow phone will not freeze.
